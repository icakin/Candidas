# Claude Code prompt — C10: make script 18 produce its figure, and restore the manuscript's figure sourcing (autonomous)

Run from the project root (`.../Candidas TPC/Candidas`). Two coupled jobs: fix the bug that stops
`18_n0_treatment_panel.R` writing anything, then repoint the manuscript at pipeline-produced figures
instead of embedded bitmaps. It changes no analysis, no constant and no fitted number — only where
figures come from, and whether one of them can be produced at all.

NOTE TO USER: launch in an auto-approving mode. Run AFTER C9's packaging PR is merged, so the pinned
environment is in place. Budget an hour or so: script 18 runs three nested Bayesian refits.

CONTEXT.

C9's diagnosis established two facts that only make sense together:

- `18_n0_treatment_panel.R` exits 0 and WRITES NOTHING. `config.R` carries a figure whitelist that
  gates `ggsave`; script 18 has a workaround; and the three nested `09_bayesian_models.R` runs inside
  18 re-source `config.R` into the global environment, undoing that workaround before any figure is
  written.
- Supplementary Figure 6 is the ONE bitmap of ten in `manuscript/draft/v3_quarto/media/media/` with
  no pipeline counterpart — because the script that should produce it produces nothing.

Supplementary Figure 6 is the figure showing the between-clade respiration activation energy under
all three N0 treatments. It was added specifically to document the N0 sensitivity, it is arguably the
most important supplementary figure in the current draft, and it currently cannot be regenerated by
anyone.

The other nine bitmaps DO map to a pipeline figure and a producing script, and eight are
byte-identical to the pipeline output. So once 18 works, restoring the sourcing is mostly a matter of
paths.

THE PROJECT POSITION: every figure in the manuscript must resolve to a file produced by the pipeline,
referenced by path. Embedded bitmaps mean a regenerated figure never reaches the paper, so the
manuscript can silently disagree with the analysis it reports. That is not an acceptable durable
arrangement, and this prompt closes it.

The full inventory is in `reports/MANUSCRIPT_FIGURE_LINKAGE.md` from C9. Read it first.
